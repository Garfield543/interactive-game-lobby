# 🎮 茶米老師的互動遊戲大廳 (Interactive Game Lobby)

專為國小課堂教學與學生自主學習設計的跨領域 Web 互動遊戲樂園。純前端技術開發、免安裝免伺服器，手機、平板、電腦三端自適應隨開即玩！

---

## 🌟 遊戲大廳首頁

- **大廳首頁**：[`index.html`](./index.html)
- **主要特色**：
  - 🖥️ 擬真遊戲畫面預覽與 Hover 動態微光效果
  - 👁️ **畫中畫即時試玩模式 (Lightbox Modal)**：免跳轉即可在視窗內即時體驗
  - 🎲 **好手氣隨機選遊戲**：課堂破冰、互動抽選必備
  - 🏷️ **主題分類篩選**：國語文益智、音樂節奏、英語打字即時過濾
  - 🔊 **Web Audio 介面音效**：內建合成音效反饋與靜音開關

---

## 🕹️ 收錄遊戲一覽

### 1. 📜 成語填填看 (`game1`)
- **主題領域**：國語文・詞彙成語・益智填空
- **遊戲機制**：
  - 隨機抽取 10 題精選四字成語，關鍵字挖空四選一填答。
  - 雙血條儀表板（答題進度條 + 15 秒倒數時間血條）。
  - 答題後即時提供正確字與完整成語典故釋義，加深記憶。
  - 支援全流程返回遊戲大廳。

### 2. 🥁 太鼓咚咚鏘：節奏大師特訓班 (`game2`)
- **主題領域**：藝術音樂・肢體律動・節奏反應
- **遊戲機制**：
  - 日式祭典風格純 Canvas 高畫質音軌渲染。
  - 敲擊「咚 (紅)」與「鏘 (藍)」，支援手機左右全螢幕隱形觸控與電腦鍵盤（F/J、D/K）。
  - 3 首原創祭典曲目（夏祭花火 / 千本櫻 / 雷神祭）。
  - 自適應速度曲線（連打漸進加速、Miss 貼心回落）與魂量表、Combo 評級。
  - 各畫面皆具備隨時返回大廳按鈕。

### 3. 🚀 太空英打防衛戰 (`game3`)
- **主題領域**：英語學習・鍵盤打字・敏捷反應
- **遊戲機制**：
  - 捍衛太空母艦防線，擊落 26 顆英文字母敵機。
  - 支援電腦實體鍵盤高速輸入與手機/平板觸控式虛擬鍵盤。
  - 26 字母全域降落雷達矩陣即時戰況監控。
  - 巡航 (Easy)、激戰 (Normal)、極限 (Hard) 3 種作戰強度。
  - 結算提供 CPM (字/分) 打字速度、命中率與作戰耗時專業數據分析。
  - 導覽列與結算畫面一鍵返回大廳。

## 🛠️ 技術架構

- **HTML5 & CSS3**：全響應式排版（RWD）、Flexbox & CSS Grid、微動效動畫。
- **Tailwind CSS & Google Fonts**：現代化遊戲 UI 介面與日式/科幻專屬字型。
- **HTML5 Canvas API**：高性能動態音軌、粒子特效與太空星空渲染。
- **Web Audio API**：零外部依賴、零延遲的純代碼音效與樂音即時合成。
- **純前端無伺服器架構**：支援本機離線執行與 GitHub Pages 一鍵部署。
