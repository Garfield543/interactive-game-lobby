# 太空英打防衛戰 (Space Typing Defense) 🚀🌌

一款以復古街機「太空射擊」為視覺風格的網頁版 26 英文字母打字練習遊戲，採用單一 HTML 檔案純前端實作，零外部依賴、支援離線運行。

---

## 🎮 遊戲核心特色與玩法

1. **太空射擊街機界面**：
   - 多層視差流動宇宙星空與隨機流星背景。
   - 底部配置配有離子引擎尾焰的防衛旗艦戰鬥機。
   - 敵機為六角霓虹外星晶體幽浮，中央標記清晰的英文字母核心。
   - 輸入正確字母時，戰艦將自動轉向瞄準目標，擊發雙管離子雷射光束與燦爛粒子爆炸特效，伴隨打擊震動感。

2. **26 個字母隨機降落（速度不一）**：
   - 遊戲啟動後，A ~ Z 共 26 個英文字母將以不同速度陸續由天而降。
   - 包含平緩巡航、中速進逼與高速突襲，挑戰玩家反應節奏。

3. **防線突破重降機制**：
   - 若敵機觸碰到底部防衛力場而未被擊中，將觸發紅色防護盾警報，並**重置回頂部重新隨機速度與位置再度降落**，直到玩家擊破消滅為止。

4. **即時狀態儀表 (HUD)**：
   - **完成數**：即時顯示當前已擊落的字母數（如 `15 / 26`）。
   - **剩餘數**：顯示尚未消滅的敵機數（如 `11`）。
   - **26 字母全域雷達矩陣**：A 到 Z 各字母狀態即時點亮（黃色=降落中、綠色=已消滅、灰色=待命）。
   - **戰況數據**：作戰計時器、即時連擊 (COMBO)、防衛積分。

5. **通關結算畫面**：
   - 全部 26 個字母擊落後自動結束遊戲，進入結算畫面。
   - 結算總耗時、打字速度 (CPM 字/分)、雷射命中率、最高連擊數與評等 (S / A / B / C)。

6. **Web Audio API 原生音效合成**：
   - 內建雷射射擊、低頻爆炸、防線告警、連擊獎勵和弦與通關凱旋樂，不需額外下載音檔。
   - 提供音效開關切換（記憶於 `localStorage`）。

7. **貼心輸入支援**：
   - 支援實體鍵盤 `e.code` 偵測，即使用戶處於中文注音/倉頡輸入法狀態下，敲擊英文鍵盤亦能精準射擊。
   - 內建虛擬觸控鍵盤，方便平板、手機與電子白板點擊遊玩。
   - 支援 `空白鍵` 或 `Esc` 暫停遊戲。
